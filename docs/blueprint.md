# **App Name**: Quiz

## Core Features:

- Question Set Selection: Allows users to select the number of questions from a pre-existing question set.
- Timed Exams: Enables setting a timer for each exam to test users under realistic time constraints.
- Score Calculation: Calculates the total score of correctly answered questions and expresses it as a percentage.
- Question Import: Enables importing question sets from a file (STT, Câu hỏi, Đáp án A, Đáp án B, Đáp án C, Đáp án D, Đáp án đúng).
- AI Answer Verification tool: Uses a tool based on LLM to compare the user-provided answers against correct answers and give feedback.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and focus.
- Background color: Light blue (#E3F2FD), providing a calm, distraction-free backdrop.
- Accent color: A contrasting amber (#FFB300) to draw attention to important actions and feedback elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, 'Inter' (sans-serif) for body text.
- Use clean, modern icons to represent actions and feedback.
- Simple and clean layout focused on the content and ease of navigation.
- Subtle animations on correct answer to reinforce user learning and increase motivation.
